# 思维导图 · Markdown Mind Map

> 粘贴 Markdown 大纲，一键生成可交互思维导图：点节点折叠、滚轮缩放、拖拽平移，导出 PNG 或 SVG。解析全在本地。

## 能做什么

- **Markdown 进，导图出** —— `#`~`######` 标题即层级，`-` / `*` / `+` / `1.` 列表项挂到最近的标题下，嵌套按缩进
- **横向 tidy 树** —— 叶子按固定行高依次排开，父节点落在首尾子节点的垂直中点，所以不会互相压住
- **折叠 / 展开** —— 点任意节点收起，旁边用 `+N` 徽标显示藏了多少个子孙
- **按层级配色** —— 根节点实心蓝，往下依次紫 / 青 / 绿 / 橙 / 粉 / 灰，深度一眼可辨
- **视图** —— 滚轮以光标为锚点缩放、拖拽平移、适应视图、全部展开 / 收起
- **导出** —— 2 倍 PNG，或颜色已经烘焙进文件的具体色 SVG（不含 CSS 变量，任何工具打开都对）
- **读文件** —— 也可以直接丢一个 `.md` / `.txt` 进来

## 实现要点

**布局是一趟遍历，不是约束求解。** 深度优先给每个叶子分配下一个空行，然后父节点移到
`(首子.y + 末子.y) / 2`。这就是 tidy tree 的经典简化版：只要所有节点行高一致（这里因为标签都是单行，成立），
它既正确又是 O(n)。

**节点宽度是估算而不是实测。** `measureWidth()` 按中日韩字符约 14px、ASCII 约 7.6px 累加，上限 300px。
好处是不依赖 SVG 是否已存在（不用隐藏容器去量、不触发重排），代价是特殊字体下略有偏差——
所以盒子左右各留了 6px 内边距吸收误差。

**折叠会重跑整次布局。** 不是把 DOM 节点原地隐藏，而是把折叠集合喂回 `layoutTree()`，
于是可见的树被重新紧凑排列、不留空洞。所以收起一个大分支时，画布会「缩」下去而不是留一片空白。

**导出是重新拼一份 SVG 字符串**，颜色写成字面量、不带 `data-id`，而不是克隆现有 DOM。
克隆会把 `var(--x)` 这类变量引用和交互钩子一起带走，别的软件解析不了。

## Markdown 支持范围（以及故意不支持的）

| 支持 | 忽略 |
|---|---|
| ATX 标题 `#` … `######` | 段落正文、引用块 |
| `-` `*` `+` 列表、`1.` `1)` 有序列表 | 代码块、表格、图片、链接（按纯文本显示） |
| 按缩进嵌套（Tab 按 2 空格算） | 行内强调 —— `**粗体**` 原样显示 |

这是有意的：思维导图是骨架，节点里再套一层富文本只会让节点读不清。

## 怎么用

下载 `index.html` 双击打开。不用安装、不用构建、不用联网。

## 明确不做的事

- 只支持单行标签；超长标签会在 300px 处截断（文字仍居中）。
- 不能直接在画布上改字 —— 改 Markdown 再重新生成。
- 没有自由摆放、也没有手动调整分支顺序。
